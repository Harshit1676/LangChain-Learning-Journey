# Artificial Intelligence and Machine Learning

Artificial Intelligence (AI) is a branch of computer science that focuses on creating machines capable of performing tasks that normally require human intelligence. These tasks include problem-solving, decision-making, understanding natural language, and recognizing images.

Machine Learning (ML) is a subset of Artificial Intelligence that enables computers to learn patterns from data without being explicitly programmed for every task. Machine learning algorithms use historical data to make predictions and improve their performance over time.

## Types of Machine Learning

There are three major types of machine learning:

1. **Supervised Learning:** The model learns from labelled data. Examples include spam detection, house price prediction, and disease classification.

2. **Unsupervised Learning:** The model learns patterns from unlabelled data. Examples include customer segmentation and clustering.

3. **Reinforcement Learning:** The model learns through interaction with an environment using rewards and penalties. Examples include robotics and game-playing systems.

## Applications of AI and ML

AI and ML are used in several industries:

- Healthcare: Disease prediction and medical image analysis.
- Banking: Fraud detection and credit risk assessment.
- Education: Personalized learning and automated evaluation.
- Transportation: Self-driving vehicles and traffic prediction.
- Agriculture: Crop disease detection and yield prediction.

## Natural Language Processing

Natural Language Processing (NLP) is a field of AI that enables computers to understand, process, and generate human language. Applications include chatbots, language translation, sentiment analysis, and text summarization.

## Document Embeddings

Document embeddings convert text into numerical vectors that represent the semantic meaning of the text. Similar documents generally have similar vector representations.

In Retrieval-Augmented Generation (RAG), document embeddings are used to retrieve relevant information from a collection of documents. When a user asks a question, the system converts the question into an embedding and compares it with stored document embeddings using similarity measures such as cosine similarity.

This allows an AI application to retrieve relevant information based on meaning rather than relying only on exact keyword matches.
